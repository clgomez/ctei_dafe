Cambiar Contraseña

Sigue estos consejos para crear una contraseña segura:

  • Usa una combinación de letras, números y símbolos.
  • No utilices contraseñas comunes o fácilmente adivinables.
  • Cambia tu contraseña regularmente para mayor seguridad.
La contraseña es obligatoria. La contraseña debe tener mínimo 8 caracteres, incluir mayúsculas, minúsculas, números y un carácter especial.
La contraseña de confirmación es obligatoria.
